## RadiusConstraint

Enforces the radius of a circle or arc.

### `center`

```python
center: int
```

Center point of the circle/arc.

### `radius_point`

```python
radius_point: int
```

Radius-bearing point (circle radius point or arc start).

### `value`

```python
value: float
```

Resolved radius value.
