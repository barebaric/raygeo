## DragConstraint

Softly pulls a point towards a target coordinate.

### `point`

```python
point: int
```

The dragged point.

### `target_x`

```python
target_x: float
```

Target X coordinate.

### `target_y`

```python
target_y: float
```

Target Y coordinate.

### `weight`

```python
weight: float
```

Pull strength.
