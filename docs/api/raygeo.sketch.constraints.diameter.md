## DiameterConstraint

Enforces the diameter of a circle.

### `center`

```python
center: int
```

Center point of the circle.

### `radius_point`

```python
radius_point: int
```

Radius-bearing point of the circle.

### `value`

```python
value: float
```

Resolved diameter value.
