## DragKnifeSpec

Parameters for the `DragKnife` transformer.

### `offset_mm`

```python
offset_mm: float
```

Distance between blade tip and pivot in millimeters.

### `swivel_angle_deg`

```python
swivel_angle_deg: float
```

Maximum direction change (degrees) swiveled with the blade down.
