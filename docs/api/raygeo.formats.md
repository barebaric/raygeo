File-format import and export.

Each sub-module translates between one external drawing format and geometry: `raygeo.formats.dxf`
reads and writes DXF, `raygeo.formats.gcode` extracts geometry from G-code, and `raygeo.formats.svg`
parses SVG and exports path data.
