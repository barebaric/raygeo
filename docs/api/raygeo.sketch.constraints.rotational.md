## RotationalConstraint

Enforces p2 is p1 rotated by angle_rad about center.

### `angle_rad`

```python
angle_rad: float
```

Resolved rotation angle in radians.

### `center`

```python
center: int
```

Rotation center.

### `p1`

```python
p1: int
```

Source point.

### `p2`

```python
p2: int
```

Rotated point.
