## EqualDistanceConstraint

Enforces dist(p1, p2) == dist(p3, p4).

### `p1`

```python
p1: int
```

First point of the first pair.

### `p2`

```python
p2: int
```

Second point of the first pair.

### `p3`

```python
p3: int
```

First point of the second pair.

### `p4`

```python
p4: int
```

Second point of the second pair.
