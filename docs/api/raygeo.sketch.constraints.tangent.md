## TangentConstraint

Enforces a line is tangent to a circle/arc.

### `center`

```python
center: int
```

Center point of the circle/arc.

### `l1`

```python
l1: int
```

First point of the line.

### `l2`

```python
l2: int
```

Second point of the line.

### `radius_point`

```python
radius_point: int
```

Radius-bearing point (circle radius point or arc start).
