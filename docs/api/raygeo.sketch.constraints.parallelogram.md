## ParallelogramConstraint

Enforces (p_width - p_origin) == (p4 - p_height).

### `p4`

```python
p4: int
```

Fourth corner.

### `p_height`

```python
p_height: int
```

Height point.

### `p_origin`

```python
p_origin: int
```

Origin point.

### `p_width`

```python
p_width: int
```

Width point.
