# CorelDRAW test assets

`circle.cdr` (RIFF container, CorelDRAW 12), `square.cdr` (ZIP
container, CorelDRAW X6) and `pages.cdr` (ZIP container, CorelDRAW X5,
two pages with text) are taken from the libcdr-test corpus,
<https://git.libreoffice.org/libcdr-test>, and are licensed under
CC-BY-SA 4.0.

The `.xhtml` files next to them hold their conversion with `cdr2xhtml`
0.1.7: one inline SVG per page inside an XHTML wrapper. They are test
fixtures only; neither the drawings nor the conversions are part of the
installed package.
